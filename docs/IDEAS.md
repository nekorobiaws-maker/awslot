# JAWSLOT -ジョースロット- 演出ネタカタログ

> **表示名は「JAWSLOT -ジョースロット-」**(U45 / 2026-08-15)。
> コード上の識別子(`window.AWSLOT`)・ディレクトリ名・内部名は **AWSLOT のまま**。
> 改名するのはプレイヤーに見える文言だけ。

AWS×パチスロゲーム「JAWSLOT -ジョースロット-」の演出・ネタ素材集。
収集: hinata-explorer / 参考画像: `docs/sample.png`

sample.png からの気づき:
- 紫筐体LED+赤サイド発光、幽霊Kiro=7図柄、BAR/チェリー/ベルが下段配置 → この構図を図柄格の土台にする
- 幽霊が大小2サイズで描かれている → 「ミニ幽霊=弱予告、フルサイズ幽霊=強カットイン」の期待度差分に転用
- 下パネルの「(台名) BIG BONUS」ロゴ+幽霊 → 当選時の下パネル点灯演出に使える
- サメは BAR 図柄の位置に差し込む想定

## 1. リール絵柄案(10個)

※ユーザー決定(2026-08-13): **S3=スイカ、EC2=ベル、IAM=チェリー** に確定。玉突きでLambdaはチャンス目格へ。

| 図柄 | 格 | 揃うと起きること |
|---|---|---|
| 幽霊Kiro | 7図柄格(最強) | 画面全紫発光+「BIG BONUS」文字が爆発、AWS無料化演出へ |
| サメ ジョージ・ジョーズ・ユージー | BAR格(準最強) | サメが筐体に噛みつくアクション→REG相当当選 |
| EC2インスタンス | ベル格(メイン小役) | 揃うとコイン払い出し。インスタンスがぐんぐん起動するアニメ |
| IAMポリシー書類 | チェリー格(レア役) | 「Access Granted!」の効果音で入賞。角IAMでも成立 |
| S3バケツ | スイカ格(レア役) | CZ抽選のチャンス役。「バケットポリシー全開放」効果音とコイン放出 |
| Lambda関数アイコン | チャンス目格(レア役) | 出現した瞬間に即発火でボーナス抽選、「関数が呼ばれました」の軽い電子音 |
| DynamoDBテーブル | リプレイ格 | テーブルが自動スケールして再遊技(もう一回転) |
| CloudWatchアラームベル | 特殊役(アラーム役) | アラーム音とともに小役成立、画面端が黄色点滅 |
| SQSキュー | ブランク寄り図柄 | 単体ではハズレ目だが「保留」として次ゲームに持ち越す演出フラグ |
| Route53ルーレット | リプレイ格2 | グルグル回って止まった先でもう一回転(名前解決演出) |

※旧IAMハズレ目の「アクセス拒否」ネタは、特定ハズレ出目(ベルこぼし目など)に「403 Access Denied」を表示する出目演出として残す。

## 3. リーチ・前兆・CZ演出(18個)

## 5. AWSサービス×スロット用語 対応辞典(37個)

| AWSサービス | 対応するスロットギミック |
|---|---|
| ALB | 複数演出ルートへの「振り分け」演出 |
| SQS | 保留(キュー)、当選抽選を次ゲームへ持ち越す保留変化 |
| Route 53 | ルーレット演出、行き先決定ガチャ |
| Glacier | 超スロー出玉、出るのは確定だが激遅 |
| Snowball/Snowmobile | 大量出玉ドカン、トラックがまとめて運んでくる |
| Spot Instance | 突然終了(中断)、期待度は高いが唐突に終わるリスク演出 |
| Auto Scaling | 増殖演出、当たりが増えるほど台が沸く |
| Lambda | 即時発火トリガー、コールドスタートは「タメ」演出 |
| CloudFront | キャッシュ即出し、過去当選パターンの高速再生 |
| WAF | ガード/シールド演出、ハズレを弾く無効化表現 |
| Shield | 究極ガード、フリーズ耐性のメタファー |
| KMS | 鍵開け演出、暗号化図柄が鍵で解除される |
| IAMポリシー | 許可/拒否オンオフ演出、許可されると役物点灯 |
| CloudWatch | 監視・警報演出、予告全般のベースシステム |
| Step Functions | ステップアップ予告そのもの、矢印が一段ずつ進む |
| EventBridge | トリガー分岐演出、複数抽選ルートへの振り分け |
| Kinesis | ストリーム流し演出、データが川のように流れる背景 |
| DynamoDB | 瞬間スケール、負荷に応じ演出強度が自動拡大 |
| Aurora | 高速回転リーチ、リール高速回転からのピタ止まり |
| RDS | バックアップ/スナップショット、過去当選の回想演出 |
| ElastiCache | 瞬間記憶演出、一度見た予告の高速再表示 |
| ECS/Fargate | コンテナ増殖演出、小キャラが量産されるステップアップ |
| EKS | オーケストラ指揮演出、複数小演出を統率するメタ演出 |
| CodePipeline | 連続演出、ビルド→テスト→デプロイの3段階疑似連 |
| CodeDeploy | デプロイ完了=大当たり確定コール |
| CloudFormation | スタック一括生成、複数役物が一斉に立ち上がる |
| X-Ray | トレース線描画、当選までの軌跡を可視化する予告線 |
| GuardDuty | 隠れキャラ検知演出、ハズレ要因を探索する演出 |
| Inspector | 精密検査演出、設定確認ミニゲーム型予告 |
| Trusted Advisor | アドバイスポップアップ予告、示唆メッセージ |
| Cost Explorer | メーター上昇演出、出玉の伸びをグラフ可視化 |
| Organizations | 複数アカウント連携演出、連動台的な同時燃焼ネタ |
| Direct Connect | 専用回線=直撃リーチ、寄り道なし一直線当選 |
| Transit Gateway | 中継地点演出、複数演出ルートがここで合流 |
| NAT Gateway | 変換演出、ハズレ目が当たり目に見えるトリック目 |
| PrivateLink | 裏ルート演出、表向きハズレでも裏で当選処理進行中の隠し要素 |
| Systems Manager | リモート介入演出、サメが遠隔操作でリールを止めにくる |
| Backup | 復元(コンティニュー)演出、負けを思わせる復活画面 |
| Elastic Disaster Recovery | 大逆転復活演出、壊滅から一発逆転の救済ボーナス |
